# PingUp — модернизация: прогресс

Рабочая ветка: `claude/pingup-2-1-messenger-update-cbnwtj`. База — PingUp 2.1.0 (схема 5).

## Аудит (кратко)

- Стек: PHP 8.3 + PostgreSQL (pdo_pgsql), фронтенд без сборки: `ui.js` (PU), `app.js` (ядро), `chat.js`, `pages.js`, `settings.js`, `experience.js` (уведомления/PWA/очередь), `calls.js` (WebRTC). Один CSS `app.css`.
- Синхронизация — **polling** (2 с активно, 15 с в фоне) + курсор `change_seq`. **WebSocket в проекте нет**: для него нужен отдельный долгоживущий процесс и прокси в Nginx — архитектурное изменение, будет предложено отдельно с подтверждением.
- Шифрование: только TLS и DTLS-SRTP у WebRTC. Сервер хранит переписку открыто. **E2EE отсутствует.**
- Поиск в чате: `messages.search` (ILIKE + pg_trgm), без счётчика и перехода к большим историям.
- Голосовые: запись `MediaRecorder`, карточка без реальной волны.
- Эмодзи/стикеры: панель в `chat.js`, GIF нет. Tenor API v2 требует ключ (Google Cloud) — без ключа функция не включается, заглушек не будет.
- Локали: uk/ru/en (1408 ключей, паритет проверяется). pl/fr/de нет.
- Тесты: `tests/integration*.py`, `tests/*-browser.cjs` (Playwright), `tests/modern-browser.cjs` — новый, растёт по этапам.

## Этап 1 — сделано

- `channels.preview` (только чтение): карточка сообщества по `invite_token` / `slug` / `conversation_id`, флаги `joined`/`banned`, для публичных каналов — 3 последних поста, для приватных — ничего кроме карточки. Не использует лимит приглашения. Rate limit 60/мин.
- Ссылки `?invite=`, `?join=` и тап по карточке в каталоге открывают предпросмотр; подписка — только кнопкой «Присоединиться». Уже участник — сразу открывается чат.
- Поисковые поля: фокус показывается на всей «пилюле» (рамка + мягкое кольцо), без квадратного outline внутри; `appearance: none` для iOS; forced-colors сохраняет индикацию.
- Пустые экраны: отдельные тексты и кнопки для «Все / Непрочитанные / Личные / Группы / Каналы / Папка / Архив», «Звонки», блокировки, журнал, админка (uk/ru/en).
- Настройки: убран пункт «Профиль», карточка аккаунта — единственный вход (с aria-label).
- Проверено: `integration_21.py` 11/11 (новые проверки preview), `modern-browser.cjs`, `update-browser.cjs` (инвайт через предпросмотр), `browser-smoke`, `messenger21-browser`, `experience-browser`, `calls-browser`; паритет локалей.

## Следующий шаг

Этап 2: кнопки звонка/видео/поиска в шапке личного чата; экран поиска по переписке (`messages.search` с `conversation_id`, общим числом совпадений и сообщений, пагинацией по курсору, переходом через `messages.list?around_id`), затем замена всплывающего глобального поиска полноэкранным.
